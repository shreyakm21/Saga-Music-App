# Saga Music App 🎵

Saga Music App is a modern music application that allows users to explore, listen to, and manage their favorite songs and playlists. It integrates with the Jamendo API to fetch random songs, including metadata and audio previews.

## Features

- 🎶 **Random Song Fetching**: Fetch random songs using the Jamendo API.
- 📄 **Song Metadata**: Display song details such as title, artist, and album.
- 📂 **Playlist Management**: Create, update, and delete playlists.
- 🛠️ **User Authentication**: Secure user login and signup.
- 🔄 **Audio Playback**: Play audio previews of the songs.
- 🎨 **Responsive Design**: User-friendly interface optimized for various devices.

## Technologies Used
**Frontend**: React, CSS
**Backend**: Node.js, Express.js
**Database**: MongoDB
**API**: Jamendo API for song data
**Authentication**: JSON Web Tokens (JWT)
